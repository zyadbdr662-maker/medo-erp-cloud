# القسم الأول: البدء

## 1. مقدمة

### 1.1. ما هو MeDo ERP؟
منصة محاسبية وإدارية سحابية متكاملة، مصممة لخدمة المؤسسات والشركات بمختلف أحجامها.

### 1.2. الميزات الرئيسية
- ✅ **سحابي بالكامل**: يعمل من أي متصفح.
- ✅ **ذكاء اصطناعي**: تحليل وتوصيات فورية.
- ✅ **فروع غير محدودة**: إدارة متعددة الفروع.
- ✅ **فوارق العملة**: دعم صنعاء وعدن.
- ✅ **محافظ إلكترونية**: جوالي، جيب، فلوسك.
- ✅ **نسخ احتياطي**: بضغطة زر.
- ✅ **واجهات SAP Fiori**: عصرية وأنيقة.

### 1.3. الباقات المتاحة
| الباقة | الميزات |
|--------|---------|
| **التجريبية** | 30 يوماً، 50 عملية |
| **الأساسية** | 3 مستخدمين، 5 فروع |
| **المتقدمة** | 10 مستخدمين، 15 فرع |
| **المؤسسية** | غير محدود، دعم مخصص |

## 3. تسجيل الدخول

### 3.1. الخطوة الأولى: فتح الرابط
افتح المتصفح واكتب الرابط الخاص بمنصتك.

### 3.2. الخطوة الثانية: إدخال البيانات
- **البريد الإلكتروني**: [بريدك]
- **كلمة المرور**: [كلمة المرور]

### 3.3. الخطوة الثالثة: النقر على "تسجيل الدخول"

### 3.4. إذا نسيت كلمة المرور
1. اضغط "هل نسيت كلمة المرور؟".
2. أدخل بريدك الإلكتروني.
3. ستصلك رسالة برمز تحقق (7 أرقام).
4. أدخل الرمز.
5. عيّن كلمة مرور جديدة.

### 3.5. الخطوة الأولى بعد الدخول
- ستظهر لك **لوحة التحكم**.
- يمكنك البدء في استخدام النظام.

---

## 4. الإعدادات الأولية

### 4.1. إعداد بيانات المنشأة
1. اذهب إلى **الإعدادات**.
2. اختر **بيانات المنشأة**.
3. أدخل:
   - اسم المنشأة (عربي/إنجليزي).
   - السجل التجاري.
   - الرقم الضريبي.
   - العنوان.
   - الهاتف.
4. اضغط **حفظ**.

### 4.2. إعداد الفروع
1. اذهب إلى **الإعدادات** → **الفروع**.
2. اضغط **"إضافة فرع جديد"**.
3. أدخل بيانات الفرع.
4. اضغط **حفظ**.

### 4.3. إعداد العملات
1. اذهب إلى **الإعدادات** → **العملات**.
2. اختر العملة الأساسية (ريال يمني).
3. أضف العملات الأخرى (دولار، سعودي).
4. حدد سعر الصرف.
5. اضغط **حفظ**.

### 4.4. إعداد الضرائب
1. اذهب إلى **الإعدادات** → **الضرائب**.
2. حدد نسبة ضريبة المبيعات (17%).
3. حدد نسبة ضريبة الأرباح (5%).
4. حدد نسبة الزكاة (2.5%).
5. اضغط **حفظ**.

# القسم الثاني: الوحدات الأساسية

## 5. إدارة المبيعات والعملاء

### 5.1. إضافة عميل جديد
1. اذهب إلى **وحدة المبيعات**.
2. اختر **العملاء**.
3. اضغط **"إضافة عميل جديد"**.
4. أدخل البيانات:
   - اسم العميل.
   - رقم الهاتف.
   - العنوان.
   - حد الائتمان.
5. اضغط **حفظ**.

### 5.2. إنشاء فاتورة مبيعات
1. اذهب إلى **وحدة المبيعات**.
2. اضغط **"فاتورة جديدة"**.
3. اختر العميل.
4. أضف الأصناف:
   - اختر الصنف.
   - أدخل الكمية.
   - السعر يُعبأ تلقائياً.
5. اضغط **حفظ**.

### 5.3. طباعة الفاتورة
- بعد الحفظ، اضغط **"طباعة"**.
- يمكنك تصديرها كـ PDF.
- يمكنك إرسالها عبر واتساب.

### 5.4. إرسال الفاتورة على واتساب
1. بعد حفظ الفاتورة.
2. اضغط **"إرسال على واتساب"**.
3. سيتم إنشاء رسالة جاهزة.
4. أرسلها للعميل.

### 5.5. كشف حساب العميل
1. اذهب إلى **وحدة المبيعات**.
2. اختر **كشف حساب**.
3. اختر العميل.
4. حدد الفترة.
5. اضغط **عرض**.

## 7. إدارة المخزون والمستودعات

### 7.1. إضافة صنف جديد
1. اذهب إلى **وحدة المخزون**.
2. اضغط **"إضافة صنف جديد"**.
3. أدخل:
   - اسم الصنف.
   - الرمز.
   - الوحدة.
   - سعر الشراء.
   - سعر البيع.
4. اضغط **حفظ**.

### 7.2. الجرد المخزني
1. اذهب إلى **وحدة المخزون**.
2. اختر **الجرد**.
3. أدخل الكميات الفعلية.
4. النظام يحسب الفروق.
5. اضغط **حفظ**.

### 7.3. التحويل بين المخازن
1. اذهب إلى **وحدة المخزون**.
2. اختر **التحويل**.
3. اختر المخزن المصدر.
4. اختر المخزن الوجهة.
5. أضف الأصناف.
6. اضغط **حفظ**.

### 7.4. التنبيهات
- **نقص المخزون**: عند وصول الكمية للحد الأدنى.
- **تواريخ الصلاحية**: قبل انتهاء الصلاحية بـ 30 يوماً.
- **الأصناف الراكدة**: لم تُبع خلال 90 يوماً.

## 13. الذكاء المالي المتقدم

### 13.1. توليد القيود
- اذهب إلى **AI Prompt**.
- اكتب المعاملة بالعربية.
- النظام يولّد القيد.

### 13.2. تحليل الأداء
- اذهب إلى **مستشار AI**.
- اسأل أي سؤال:
  - "ما هو الصنف الأكثر ربحية؟"
  - "ما هي الفروع الأكثر مبيعاً؟"
- النظام يجيب فوراً.

### 13.3. التنبؤ بالسيولة
- النظام يحلل التدفقات.
- يتنبأ بالسيولة القادمة.
- يقدم توصيات.
